# Frontend Mentor - Advice generator app

This is a solution to the [Advice generator app challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/advice-generator-app-QdUG92_zz). 

## Features

- Generates random advice using the [Advice Slip API](https://api.adviceslip.com/).
- Responsive layout for mobile and desktop.
- Hover states for interactive elements (dice button).

## Built With

- HTML5
- Tailwind v4
- JavaScript (Fetch API)
